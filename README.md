# Pokédex Angular

Aplicação Pokédex desenvolvida com Angular 19, consumindo a PokéAPI.

## Funcionalidades

- 🔍 Buscar pokémon por nome
- 📋 Listagem paginada com cards coloridos por tipo
- 📊 Detalhes com estatísticas base, habilidades, altura e peso
- 🎨 Cores dinâmicas por tipo do pokémon
- 📱 Interface responsiva

## Tecnologias

- Angular 19
- TypeScript
- PokéAPI (https://pokeapi.co)
- CSS3

## Como rodar

```bash
npm install
ng serve
```

Acesse `http://localhost:4200/`
